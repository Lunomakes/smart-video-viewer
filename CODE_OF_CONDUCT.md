# 协作行为准则 / Code of conduct

本准则适用于本仓库的 Issue、PR、评审及相关协作。
This policy applies to repository issues, pull requests, reviews and related collaboration.

尊重不同背景与经验；讨论代码和设计，不攻击个人。禁止骚扰、歧视、威胁、泄露私人信息和持续的恶意干扰。提供具体、可操作的反馈，接受善意纠正。
Respect different backgrounds and experience levels. Critique code and design, not people. Harassment, discrimination, threats, disclosure of private information and persistent malicious disruption are not acceptable. Give specific, actionable feedback and accept good-faith corrections.

维护者可要求修正内容、隐藏或移除不当内容，并限制重复违规者的参与。需要报告时，先向维护者 @Lunomakes 请求私密沟通方式；不要在公开讨论中暴露受影响者身份或敏感证据。本准则为本项目简版规则，不宣称采用或完整实现其他组织的行为准则。
Maintainers may request corrections, hide or remove inappropriate content, and restrict repeat offenders. Request a private contact channel from @Lunomakes before sharing sensitive evidence or identifying affected people. This is a short project-specific policy, not an adoption of another organization’s code.
