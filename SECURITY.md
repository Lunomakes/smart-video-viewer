# 安全报告 / Security

当前仅针对 main 分支和最新开发版本评估安全修复，没有承诺响应时限或旧版本支持周期。
Security fixes are assessed for main and the latest development version. No response SLA or older-version support window is promised.

**不要在公开 Issue 或 PR 中披露漏洞利用步骤、凭据或受影响用户信息。**
**Do not disclose exploit details, credentials or affected-user data in public issues or PRs.**

请通过 GitHub [私密漏洞报告](https://github.com/Lunomakes/smart-video-viewer/security/advisories/new) 联系维护者。提供脱敏的版本信息、影响范围、最小复现条件和建议修复，不要附真实令牌、Cookie 或完整浏览记录。
Use GitHub’s [private vulnerability reporting](https://github.com/Lunomakes/smart-video-viewer/security/advisories/new) to contact the maintainer. Include redacted version information, impact, minimal reproduction conditions and suggested fixes. Never attach live tokens, cookies or browsing history.

如果报告入口不可用，先向 @Lunomakes 请求私密沟通方式，不在公开讨论中发布漏洞细节。
If the reporting entry point is unavailable, ask @Lunomakes for a private channel before sharing details; do not disclose them in public discussions.
